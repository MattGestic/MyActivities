# Projects

**This folder is intentionally empty on this branch.**

`main-projects-hub` carries the index, the governance, and the resources. It carries no application code.

Each application lives in `Projects/<App-Name>/` on **its own orphan branch**. See the register in the [repository README](../README.md) for which branch holds which application.

To find an application's code, switch to its branch:

```bash
git checkout p6-milestone-dashboard
ls Projects/P6-Milestone-Dashboard/
```

To create a new one, follow `Governance/00-repository-model.md`.
