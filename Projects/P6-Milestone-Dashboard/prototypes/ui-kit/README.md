# UI kit gallery (D-31 Stage A)

Standalone harness for the `ui-*` modules in `src/modules/`. It uses no app data.

| File | What it is |
|---|---|
| `demo-shell.html` | The full shell, left nav, cards and controls on sample data. It loads the module files directly; open it in a browser. |
| `index.html` | The gallery: the live demo at 390, 768 and 1440 px, the tokens, and each module's `MODULE.md`. |
| `build.py` | Inlines the modules and docs into `dist/ui-kit-gallery.html`, a single file that needs no server. Re-run it after any module change. |
| `dist/` | Generated by `build.py`. Never edit it by hand. |

Tests:
- `node tools/ui_kit_test.mjs` is the pure logic test.
- `node tools/ui_kit_check.mjs` is the browser check at 390, 768 and 1440 px. It measures padding, gaps, widths, wrap and truncation, keyboard behaviour, events and motion tokens, then loads the built gallery.
