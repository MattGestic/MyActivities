SRET UI kit

The shared building blocks for the dashboard redesign. They are built here on their own, with no app data, so they can be reviewed, reused and redeployed. They cover the containers (shell), cards and controls, and the left navigation. The dialog form, right panel and filter bar follow in Stages B to D, on these same tokens.

Live demo

The full shell with the left nav, running on sample data. Switch the width to see the phone drawer, the tablet rail and the desktop layout. Try the Collapse control at the bottom of the nav, the menu button on phone, Details (opens the right region), the tabs, the switches and the chip remove.
