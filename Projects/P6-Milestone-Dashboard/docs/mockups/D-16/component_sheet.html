D-16 design standard: component sheet

Every control in the dashboard, drawn to one standard based on the Windows UI kit (Fluent 2): 24px controls on desktop and 32px on touch screens, 12px control text, 4px corners, and spacing on a 4px grid. Colours are the app's own tokens. The written spec is docs/ux/design-standard.md. Sign-off on this sheet is the gate before any app code changes.
