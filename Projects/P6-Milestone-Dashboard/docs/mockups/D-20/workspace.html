D-20a: two-sided workspace mockups (rev 3)

Static mockups only, no app code changed. Draws the hard line between the annotation layer (Workspace, left) and the schedule/format layer (Data & view, right). Rev 3: the Workspace side is now an always-visible left icon rail, full height, with its panel opening beside it rather than nested inside it; Data & view keeps its own docked rail-plus-panel, opened from the header. Re-houses the D-17b Sources/Annotations tab content and the D-19 notes panel into these two sides. Source: the D-20 Two-sided workspace and D-19 Notes panel plan sections. Reference for control conventions: docs/mockups/D-16/component_sheet.html; reference for the panel patterns being re-housed: docs/mockups/D-17/data_manager.html.

1. Overview: the always-visible Workspace rail

The header's Workspace toggle is gone. In its place, a slim vertical icon rail sits on the left edge of the app, below the header, full height, at all times: Notes (with an open-note count badge), Comments & markups, User milestones and Lists, each with a tooltip. The rail is never hidden, only its panel is. Clicking an icon opens that section's panel beside the rail; clicking the active icon again, or the panel's ×, closes the panel back down to the bare rail and the board reclaims the width. The active icon is highlighted. On the right, Data & view still docks as a rail-plus-panel pair, opened from the header's Colour & theme or Import & settings buttons (section 2); it is closed here so the collapsed and single-panel states are easy to read. A label strip at the open panel's top still names the layer, "Your annotations", and the Workspace rail and panel header keep a distinct workspace slate (--color-bg-workspace-hd), related to but visibly different from the app header navy and from the Data & view panel, which stays the app header colour. Below the app header sits the top filter bar: Date range (Weeks, a W/E field), Mode (Highlight / Show only) and Fit columns. Click a rail icon below to try the live toggle.

2. Header right-hand buttons, and compact mode

Desktop, left to right, each a plain icon button with a tooltip: Light/Dark (toggles the theme; the icon shows the mode a click switches to), Print (A3 preview), Save as (was "Save as new dashboard" in the old More actions menu, now its own button), Colour & theme (opens the View controls section of the right panel), Import & settings (the gear, rightmost, opens the Data & view panel at Sources / Import / Data settings). One consistent treatment throughout: icon-only with a tooltip at this width, never a mix of labelled and unlabelled buttons in the same row. The More actions menu no longer exists at this width: Filter row toggle is removed outright, and Reset row marks has moved into the Workspace's Comments & markups section (section 4).

3. Notes with status

Each note gets a status pill (Open / Sent / Pending / Closed) to track its progress against the master schedule, in distinct token colours: Open is neutral, Sent is the accent/blue used for on-track markers, Pending is amber, Closed is a muted green. A status filter chip row sits beside This period / All periods. #ID chips still link a note to several milestones; the second note here links three.

4. Comments & markups

The milestone comment threads across the board, filterable by period, status and milestone. Below that, the mounted annotation layers as a stack: Local edits is always the top layer, two mounted files sit below it, each with an on/off switch, Merge into Local edits and Remove. The three exports come next, moved down from the old More actions menu. Last is Reset row marks, moved here from the header's old More actions menu as a secondary action with a one-line explanation of what it does and does not touch. Its inline confirmation follows the design standard: message full width, Cancel at bottom-left, Reset at bottom-right; it is shown already expanded below so the layout can be reviewed without a click.

6. Right side: Data & view sections

The Data & view rail now carries seven sections; five representative slices follow. View controls folds in the current Customize sidebar's groups, and now opens with a Theme control (Light / Dark / System) at the top, moved in from the old header theme toggle; the light widget below shows Light selected, the dark widget shows Dark selected. Sources drops User-defined (it now lives in the Workspace's User milestones section) and shows schedules only; Import pairs a file drop with a mapping summary; Data settings covers thresholds and the week-ends-on setting. Help and About are new: short placeholder content only, to be written up properly once the rest of this revision is settled.

7. Import confirmation sequence

When a schedule import finishes, the panel switches to Sources, scrolls the new card into view and plays a short highlight: an accent-tint background with an outline that fades over 1.2 seconds. With prefers-reduced-motion the highlight is a static outline for 2 seconds instead of a fade. The same sequence runs on the Workspace side when an annotation file is mounted. 8. Phone 390: each side as a full-screen overlay

On phone, Workspace and Data & view each open as a full-screen overlay rather than a docked panel. Design call: the vertical rail becomes a top segmented tab row rather than a bottom bar, so it sits directly under the app header in the same reading order the desktop rail uses (left edge, top to bottom becomes left to right), and it does not compete with the browser's own bottom chrome on a phone. It scrolls horizontally if it does not fit; the active tab shows the section, exactly as the active rail icon does on desktop.
