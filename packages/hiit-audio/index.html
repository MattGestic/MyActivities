Theme compatible

The component reads RepStack’s shared color and font tokens. Switching the host document between dark and light themes updates it automatically.

Pause, resume, terminate

The countdown remains the timing authority. Pause freezes the audio clock and preserves cue position; resume continues both timelines. Terminate cancels current and future cues.

await pauseTimerAudio();
await resumeTimerAudio();
terminateTimerAudio();
